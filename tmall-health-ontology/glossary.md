# 业务术语与黑话表（glossary）

> 用途：让 agent 听懂小二的日常说法，并把口语映射到本体里的对象/指标/维度。
> 维护方式：每周从 agent「没听懂 / 理解错」的对话里补录；业务 owner 负责审核。
> 映射列填 `ontology.yaml` / `metrics.yaml` / `dimensions.yaml` 里的 id，没有对应就留空。

| 术语 | 含义 | 同义词/变体 | 映射到本体 | 备注 |
|------|------|-------------|-----------|------|
| 大盘 | 天猫国际保健行业整体 | 行业大盘、整体盘子 | category（试点范围根类目） | 默认范围见 metrics conventions |
| 货盘 | 一组商品的集合（选品结果） | 盘货、货品结构 | item 的集合 | 常见问法："帮我盘一下 XX 货盘" |
| 坑产 | 单个资源位/坑位产出的 GMV | 坑位产出 | pay_gmv（按资源位维度） | 需要资源位维度时另行建模 |
| 高退 | 退款率显著偏高 | 退款高 | refund_rate | 阈值：<TODO 行业基准，如 >X%> |
| 动销 | 有成交的商品 | 动销率、动销款 | 派生指标：有支付的 item 数 / 在售 item 数 | 试点期可先不建指标，口头解释 |
| 类目渗透率 | 某类目买家占行业买家的比例 | 渗透 | 派生指标 | <TODO 是否纳入 v1> |
| 直通车 | 关键词付费推广产品 | 关键词推广 | channel=付费推广 | 细分渠道 |
| 万相台 | 场景化付费投放产品 | 万相台无界 | channel=付费推广 | 细分渠道 |
| 客单 | 客单价 | 客单价 | atv | 注意与"件单价"区分：件单价=GMV/件数 |
| 新客 | 首次购买的买家 | 拉新、首购 | new_buyer_ratio 的分子 | 店铺新客/品牌新客口径不同，见 metrics |
| 老客 | 有历史购买的买家 | 复购人群 | user_group=老客 | |
| 保税 | 保税仓发货模式 | 保税仓、BBC | trade_mode=保税 | 时效快、退款率低于直邮（一般规律） |
| 直邮 | 海外直邮模式 | 海外直邮、BC直邮 | trade_mode=直邮 | |
| 蓝帽子 | 国产保健食品注册/备案标志 | 保健食品批文 | — | 跨境商品**不适用**蓝帽子体系，常见误解，agent 需能澄清 |
| 膳食营养补充剂 | 跨境保健品的规范称谓 | 膳食补充剂、DS | category | 合规话术中避免称"保健食品" |
| 白牌 | 无知名品牌背书的商品 | 工厂牌 | brand 属性（可加标签） | |
| 预售 | 大促前定金预售阶段 | 定金、付定 | campaign.phase=预售 | 定金是否计 GMV 见 metrics pitfalls |
| 开门红 | 大促现货开卖第一波 | 第一波段 | campaign.phase=开门红 | |
| 返场 | 大促结束后的返场期 | 返场期 | campaign.phase=返场 | |
